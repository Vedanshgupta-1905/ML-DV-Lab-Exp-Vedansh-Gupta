# Experiment 4: Interactive Dashboard

## Aim
Implement Interactive Dashboard using Power BI Desktop.

## Dataset
[retail_sales.csv](retail_sales.csv) (synthetic demonstration data).

## Procedure
Create cards for total sales and profit, a category bar chart and monthly line chart. Add slicers for Region, Category and Date (Between). Use Format > Edit interactions to verify that slicers filter the visuals. DAX: `Total Sales = SUM(retail_sales[Sales])`; `Total Profit = SUM(retail_sales[Profit])`.
