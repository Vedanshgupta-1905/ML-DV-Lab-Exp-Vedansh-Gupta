# Experiment 1: Getting Started with Power BI

## Aim
Implement Getting Started with Power BI using Power BI Desktop.

## Dataset
[retail_sales.csv](retail_sales.csv) (synthetic demonstration data).

## Procedure
Import CSV using Home > Get data > Text/CSV. Create a table with Category and Sales; clustered bar chart with Category on Y and Sum of Sales on X; line chart with Date on X and Sum of Sales on Y.

## Expected result
The configured visual or transformation should demonstrate the stated aim. Save your Power BI report and add a screenshot of your actual output after completing the procedure.
