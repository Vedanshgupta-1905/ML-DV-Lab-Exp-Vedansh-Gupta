# Experiment 5: Geo Visualization

## Aim
Implement Geo Visualization using Power BI Desktop.

## Dataset
[retail_sales.csv](retail_sales.csv) (synthetic demonstration data).

## Procedure
Set City, State and Country data categories. Use Azure Maps visual (if enabled), assign City/State/Country as location hierarchy and Sum of Sales as bubble size. Alternatively use a filled map by State. Add Profit as tooltip. Verify locations in India.

## Expected result
The configured visual or transformation should demonstrate the stated aim. Save your Power BI report and add a screenshot of your actual output after completing the procedure.
